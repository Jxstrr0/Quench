# Names used in Quench

Check section 8 of `.github/LONGLIGHT-STUDIO.md` before adding a name, then add it here.

| Name | What it is | Added |
| --- | --- | --- |
| Skerrow Isles | The invented cold North Atlantic island country | PR 0 |
| Aldersay | The harbour town; the smithy is a stone shed on its quay | PR 0 |
| Skerrow crown (`kr`) | Money, written `kr 1,250` | PR 0 |
| Skerrow Cutlers' Guild | Rates smiths: Apprentice, Journeyman, Master | PR 0 |
| The Proving | The Guild's test day | PR 0 |

Do not use: Kestrel, Kessel, Harbourline, Hollis, Tidewater, Heron, Lantern,
"Prairie", or another country that starts with V.

Steel grades (1084, 1095, 5160, 52100, W2, 15N20, 80CrV2) are real generic standards, not brands.
