# Quench

A bladesmithing game by Longlight Interactive.

Heat the steel, read its colour, hammer it to shape, then harden it in the
quench and find out at the trial what you really made.

- Play: https://quench.longlight.games/ (until the domain is set: https://jxstrr0.github.io/Quench/)
- Plan: [docs/QUENCH-PLAN.md](docs/QUENCH-PLAN.md)
- Progress: [docs/STATUS.md](docs/STATUS.md)

## Run it

```
npm install
npm run dev
```

Checks: `npm run lint`, `npm run test`, `npm run build`.
